Your phone. A question. A whole world to explore.

The easiest way to create an ORB: enter a question in Star Navigator. No account, API key, file or prompt copying needed.

An AI assistant is an app you can talk to: ask questions, explore ideas, or get help writing. If you prefer using your own AI assistant, you can begin with a free chat account. No coding experience is needed.

Just want to explore?

Open an existing ORB in your phone’s browser. You do not need an AI account to read the website or play its available recordings.

Is this an AI agent?

Start with the ordinary chat assistant. An agent can also take actions using tools; those features may require extra permissions or a paid plan. The ORB conversation below does not require an autonomous agent, API key, or developer account.

2. Say hello

Open a new chat. Copy this message, paste it into the message box, and tap Send. You can edit the topic first.

Try “Explain that more simply,” “Give me an example,” or “What do we still not know?” There is no special vocabulary to learn.

3. Turn curiosity into an ORB

  1. Open the ORB prompt page and copy its full prompt.
  2. Return to your AI chat, paste it, and send it. Then type a topic, such as /orb ocean life.
  3. Follow a numbered branch or a suggested direction. Ask for Spanish if you prefer.
Get the ORB prompt ↗

A prompt is simply a set of instructions you paste into a chat. Typing /orb alone does not install a skill. The chat version explores ideas in conversation; it does not automatically create the rotating website or narrated video.

When you want a shareable file, ORB Share provides an authoring brief and a reader for your saved text ORB.

A few useful habits

Ask for sources, open important links, and check claims that matter. AI can be mistaken. Keep passwords and private information out of practice chats.
